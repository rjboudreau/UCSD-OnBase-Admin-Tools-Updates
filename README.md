# UCSD OnBase Admin Tools Update Feed

This repository hosts the public in-app update feed for UCSD OnBase Admin
Tools. The application reads `latest.json` from this repository and downloads
the matching release archive from the same branch.

Current feed URL:

`https://raw.githubusercontent.com/rjboudreau/UCSD-OnBase-Admin-Tools-Updates/main/latest.json`

The source application repository remains private.
